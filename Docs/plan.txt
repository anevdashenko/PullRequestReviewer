ЭТАП 1: Проектирование и АрхитектураАрхитектура системыFrontend: SPA на Vite (React/Vue) для настроек.Backend: Node.js (Fastify/Express) API + Воркеры.Database: PostgreSQL для хранения доступов и логов.Интеграция: Webhooks от GitHub/GitLab для триггеров.AI слой: LangChain или прямой вызов API OpenAI/Anthropic.Схема базы данных (Минимум)Таблица users: ID, email, пароль.Таблица repositories: ID, user_id, git_provider, repo_url, access_token.Таблица rules: ID, repo_id, prompt_template, exclude_files.Таблица review_logs: ID, repo_id, pr_number, status, ai_response.ЭТАП 2: Настройка окружения и Сборка (Docker)Шаг 1: Инициализация проектаСоздать корневую директорию проекта.Разделить на папки /frontend, /backend, /docker.Шаг 2: Создание Docker ComposeНастроить контейнер postgres:16-alpine.Настроить контейнер backend с пробросом портов.Настроить контейнер frontend для разработки.Объединить контейнеры в одну сеть app-network.ЭТАП 3: Разработка Бэкенда (Node.js + PostgreSQL)Шаг 1: Инициализация и БазаРазвернуть Fastify или Express сервис.Подключить ORM (Prisma или TypeORM).Написать миграции для таблиц из Этапа 1.Шаг 2: Реализация REST APIPOST /api/auth — авторизация пользователя.POST /api/repos — добавление репозитория и токена.GET/PUT /api/rules — управление промптами и правилами.Шаг 3: Прием Вебхуков (Webhook Handler)Создать эндпоинт POST /api/webhooks/github.Реализовать валидацию секретной подписи GitHub.Отфильтровать события: реагировать только на pull_request.opened и pull_request.synchronize.ЭТАП 4: Интеграция с Git и AIШаг 1: Получение кода (Git API)Подключить библиотеку @octokit/rest для GitHub.По событию вебхука запрашивать Diff пул-реквеста (GET /repos/{owner}/{repo}/pulls/{pull_number}).Разбить Diff на отдельные файлы и измененные строки.Шаг 2: Запрос к ИИСформировать системный промпт из настроек базы данных.Передать Diff в API (например, GPT-4o-mini для экономии).Запросить ответ строго в формате JSON (файл, строка, комментарий).Шаг 3: Публикация ревьюПарсить JSON-ответ от ИИ.Отправить комментарии в PR через GitHub Reviews API (POST /repos/{owner}/{repo}/pulls/{pull_number}/reviews).ЭТАП 5: Разработка Фронтенда (Vite + Admin)Шаг 1: Каркас интерфейсаИнициализировать Vite + React/Vue + TailwindCSS.Установить готовую библиотеку компонентов (shadcn/ui или Component UI).Шаг 2: Экраны (Всего 3 страницы)Login: Простая форма авторизации.Dashboard: Список подключенных репозиториев и кнопка "Добавить".Settings: Текстовое поле (textarea) для редактирования системного промпта ИИ и список чекбоксов для правил.ЭТАП 6: Тестирование и MVPШаг 1: Локальный запуск вебхуковУстановить ngrok или localtunnel.Пробросить локальный порт бэкенда в сеть.Вставить полученный URL в настройки Webhook тестового репозитория GitHub.Шаг 2: Сквозной тест (E2E)Создать тестовую ветку с заведомо плохим кодом (например, hardcoded console.log или sql-инъекция).Открыть Pull Request.Проверить появление комментариев от бота в течение 10-20 секунд.
